' သတိပြုရန် ' Data သိမ်းဆည်းမှု အသိပေးချက်

ဤ Free Free POS!သည် မည်သူမဆို အမြဲတန်း အခမဲ့သုံးဆွဲနိုင်အောင်ဖန်တီးထားခြင်းဖြစ်ပါသည်။

Free Free POS! စနစ်မှ ထည့်သွင်းသော ကုန်ပစ္စည်း၊ အရောင်းစာရင်း၊ ဝန်ထမ်းနှင့် ဆက်တင် ဒေတာများကို Server ပေါ်တွင် မသိမ်းဆည်းဘဲ သင့်အသုံးပြုနေသော သင့် phone (သို့) device ရဲ့ Browser Data ထဲတွင်သာ လုံခြုံစွာ သိမ်းဆည်းထားပါသည်။

  • Browser Cache / Site Data များကို ရှင်းလင်းခြင်း Clear Browsing Data ပြုလုပ်ပါက ဒေတာများ ပျက်သွားနိုင်ပါသည်။ Browsing history ကို clearလုပ်ရင်တော့ သင့်dataမပျက်ပါ။ Dataကိုဖျက်မှ ပျက်ပါသည်။
  • Phone (သို့) deviceပြောင်းသုံးသည့်အခါ dataကူးပြောင်းရန်အတွက် Settings > Backup & Data ထဲမှ Backup ဖိုင် (Google Drive) ကို ပုံမှန်သိမ်းဆည်းထားသင့်ပါသည်။
